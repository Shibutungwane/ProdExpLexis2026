# Angular Project  – ProdExpLexis2026

This project is a base Angular application demonstrating a responsive layout, clear navigation, and standalone components using Angular's modern bootstrapping approach.

## Features

- Standalone Angular components (no root NgModule)
- Router setup using providers
- Views:
  - Catalog List (default/home)
  - Product Details (parameterized route)
  - Favorites
  - Admin (guarded)

Prerequisites

- Node.js >= 18.x
- npm >= 9.x
- Angular CLI >= 16.x


Installation

```bash
# Clone the repository
git clone https://github.com/Shibutungwane/ProdExpLexis2026.git
cd ProdExpLexis2026

# Install dependencies
npm install

ng serve

application Link http://localhost:4200
